# Utilisation de l'IA

## En résumé

Toutes les idées et toutes les modifications du site viennent de moi et de ma maquette Figma. La partie code a été gérée par Claude Code, un outil d'IA d'Anthropic que j'ai utilisé directement dans le dossier du projet.

## Ce qui vient de moi

- La direction artistique : noir, blanc et gris, IBM Plex Mono, crochets pour les actions, parenthèses pour les intitulés.
- La maquette Figma, qui sert de base à chaque page.
- La structure du site et la façon de naviguer.
- Le choix des projets, des images, des photos et des couleurs.
- Mes œuvres, mes affiches, mes covers et le projet TiK•TaK.
- Chaque demande de changement : ce qu'il fallait ajouter, enlever ou refaire, et pourquoi.
- Les retours sur le rendu, quand quelque chose ne me plaisait pas. Par exemple, j'ai fait retirer les effets de zoom sur les images pour garder un site sobre.

## Ce que Claude Code a fait

- Écrire tout le code du site : les pages, les composants, les animations et l'adaptation au téléphone.
- Reprendre les éléments de ma maquette Figma pour les mettre dans le site.
- Préparer les images : recadrages, exports du Figma et icône d'onglet.
- Proposer une première version de certains textes de projets à partir de mes explications. Je les ai relus et corrigés quand il le fallait.
- Corriger les bugs d'affichage.

## Les règles que j'ai données

- Aucun commentaire dans le code.
- Utiliser les couleurs et les tailles de ma charte.
- Deux styles de texte seulement : petit en casse normale et grand en majuscules.
- Rester simple et sobre, sans effets de zoom ni d'apparition sur les images.
- Me répondre en français.

## Vérification

Je regarde chaque changement dans le navigateur avant de passer à la suite, et je redemande une correction quand le rendu ne correspond pas à ce que je veux.
