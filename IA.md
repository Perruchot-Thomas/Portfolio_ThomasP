# Utilisation de l'IA

## Outil

Claude Code (Anthropic), utilisé dans le dossier du projet pour écrire et ajuster le code du site.

## Ce que l'IA a fait

- Écrire le code Astro / Tailwind / TypeScript des composants (header, menu, loader, hero, About, Projets)
- Mettre en place les animations GSAP et le défilement Lenis
- Convertir mon lettrage Figma en chemins SVG
- Générer des visuels provisoires pour tester la section Projets
- Corriger les bugs d'affichage et d'alignement

## Ce que j'ai fait

- Concevoir la direction artistique et la maquette (Figma)
- Choisir les polices, les couleurs, les textes et les photos
- Piloter chaque étape par retours précis sur le rendu (tailles, positions, comportements)
- Décider quelles librairies garder ou retirer après essai

## Cadre que j'impose à l'IA

- Aucun commentaire dans le code
- Utiliser mes tokens de design, deux styles de texte uniquement (Roboto)
- Rester sur des interactions légères

## Vérification

Je relis et teste chaque rendu dans le navigateur avant de passer à l'étape suivante.
